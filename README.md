# NoPython-Agent
"No tool definitions, no JSON schemas, no Python."

Great content by Philipp Schmid at AI Engineer Worlds Fair. The difference between Steps and Turns made a lot clear about what agents are supposed to do. 
I wanted to try this hands-on, so created a Regulation-Compliance Agent, gave it access to company policies and new regulations set by regulators (RBI, SEBI), and the agent assists the compliance team in finding affected areas.

Simple use case, but the method was really interesting. The biggest question I was asking was HOW?
